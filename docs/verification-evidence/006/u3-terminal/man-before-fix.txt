NAME
     tusk-completion - Generate a shell completion script

SYNOPSIS
     tusk completion  [flags]

DESCRIPTION
     Generate a shell completion script

OPTIONS
     -h, --help[=false]      help for completion

OPTIONS INHERITED FROM PARENT COMMANDS
     --auto-complete-parent[=false]       Complete parents when
     all children are done
