NAME
     tusk-completion - Generate a shell completion script

SYNOPSIS
     tusk completion <bash|zsh|fish> [flags]

DESCRIPTION
     Generate a shell completion script

OPTIONS
     -h, --help[=false]      help for completion

OPTIONS INHERITED FROM PARENT COMMANDS
     --auto-complete-parent[=false]      Complete parents when all children are done

     --timezone=""      Date timezone (IANA name)

SEE ALSO
     tusk(1)
