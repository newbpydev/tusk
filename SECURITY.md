# Security reporting

There is no published supported release yet. Security fixes target the current
source tree; no response-time or older-version support promise is made.

GitHub private vulnerability reporting was **disabled** when checked on
2026-10-01. The verified repository owner is
[newbpydev](https://github.com/newbpydev). Use that profile's available contact
options to ask for a suitable reporting channel before sending sensitive details.
No private email/contact address is currently published here. If no private
channel is available, a public issue may ask the owner to arrange one; do not
include an exploit, credentials or personal data. Public issues are not confidential.

Describe the affected source/version, OS/architecture and impact once an
appropriate channel is arranged. Provide a minimal sanitized reproduction.
Never upload a task database, WAL/SHM, private notes or environment dumps.
Ordinary bugs belong in [issues](https://github.com/newbpydev/tusk/issues).

The maintainer must recheck the setting and update this policy before claiming
private GitHub reporting is available. Build-time dependencies and checked-in
replacements retain separate upstream terms and provenance in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
